# v0.6.0 update record

The Windows Pixel Core moved from v0.5.0 to v0.6.0.

The AHK bridge is configurable from the GUI and persists settings in ahk_settings.ini. The settings mirror the actual AutoHotkey 1.1 controls used by the bridge.

A deterministic fishing simulator was added to regression-test catch detection, reel-marker tracking, target-zone detection, and completion detection across multiple display resolutions.
