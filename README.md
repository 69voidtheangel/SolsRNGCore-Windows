# SolsRNGCore-Windows • Pixel Core v0.5.0

Windows-first Sol's RNG automation core focused on pixel detection, resolution-aware calibration, pixel-only fishing, and a broad EndSol-style feature suite.

## v0.5.0

- AutoHotkey 1.1 input bridge. The bundled .ahk file is written for AHK 1.1, not AHK v2.
- Screenshot-guided Calibration Studio with exact resolution profiles and scale-from-nearest support.
- Pixel-only fishing: cast, catch-pixel detection, reel-bar tracking, completion detection, close, auto-sell, and failsafes.
- Screenshot webhooks for rare/unknown biomes, aura, merchant, fishing, rejoin, manual, and periodic events.
- EndSol-style modules covering Memory Match, Quest Board, merchant OCR/buying, custom paths, egg routes, potion/item actions, auto-pop buffs, multi-instance management, Sol's Book caching, and remote control.
- Feature coverage checklist in ENDSOL_FEATURES.md.

UI-dependent actions require exact per-resolution calibration; the macro does not guess coordinates.

See CHANGELOG.md for this version's changes.
