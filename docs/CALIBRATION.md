# Calibration Map

Every resolution profile stores its own coordinates. Do not copy coordinates between modes unless you use Scale From Nearest and then verify them.

## Fishing

Points: fishing_fish_button, fishing_catch_pixel, fishing_completed_pixel, fishing_close_button, fishing_first_item, fishing_sell_button, fishing_confirm_sell, fishing_idle_point, fishing_shaded_pixel.

Region: fishing_reel.

## EndSol-style feature anchors

Memory Match uses memory_tile_0 through memory_tile_19.

Quest Board uses the quest_region region plus quest_accept and quest_dismiss points.

Merchant uses merchant_region plus optional merchant_buy:<itemname> points.

A feature will report missing calibration instead of clicking guessed coordinates.
